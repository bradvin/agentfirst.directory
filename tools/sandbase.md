SandBase provides hosted execution workspaces, model APIs, and data APIs for AI agents. Its sandbox gateway supports the E2B SDK and uses the same SandBase account as the API catalog.

## So agents can...

- Create a workspace and run a script generated during a task.
- Retrieve generated files before stopping the workspace.
- Use the same account for sandbox execution and calls to models or data APIs.
