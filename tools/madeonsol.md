MadeOnSol is real-time onchain data infrastructure for Solana and Robinhood Chain. It serves KOL activity, wallet intelligence, token and deployer analytics, and DEX data through a REST API, WebSockets and webhooks, with official TypeScript, Python and Rust SDKs. Agents can use it through dedicated MCP servers, Solana Agent Kit and ElizaOS plugins, with either an API key or keyless x402 pay-per-call.

## So agents can...

- Look up what tracked KOL wallets are buying and selling, and detect several KOLs accumulating the same token.
- Check a wallet's statistics, flags and current holdings before acting on its activity.
- Pull token risk inputs, deployer reputation and trade history for a token.
- Pay for individual calls over x402 within a capped budget instead of creating an account.

The service is read-oriented data access: it does not take custody of funds or execute trades on the agent's behalf.
