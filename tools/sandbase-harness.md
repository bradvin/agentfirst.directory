SandBase Harness is a local-first, self-hosted runtime for stateful AI agent sessions. It provides persistent state, MCP toolsets, credential and approval controls, artifacts, audit and replay, plus local, Docker, Kubernetes, and self-hosted worker execution backends. Isolation depends on the selected deployment backend.

## So agents can...

- Keep session state, events, memory, and artifacts across long-running tasks
- Use governed MCP tools with credential and approval controls
- Inspect, audit, replay, and recover agent work through the runtime and Console
