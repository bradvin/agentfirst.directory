AgentSEO is an SEO intelligence API for agents and developers. It exposes rank tracking, content gap analysis, keyword clustering, local visibility, and AI Overview extraction through REST, hosted MCP, and Node.js and Python SDKs. Core workflow responses include structured decisions, evidence, recommended actions, limitations, and next calls.

## So agents can...

- Run SEO research and monitoring workflows without parsing dashboard-oriented reports
- Queue longer analyses and follow their progress through polling, event streams, or webhooks
- Use structured evidence and recommended next calls to choose the next workflow step
