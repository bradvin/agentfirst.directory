OneCLI v2 is a team agent harness for running durable, sandboxed personal agents with memory, skills, schedules, communication channels, and centrally governed access. Its hosted or self-hosted control plane gives teams a shared dashboard and policy layer while agent runners execute on customer-controlled infrastructure.

The product also retains its credential-gateway role: an encrypted vault and intercepting HTTP proxy inject scoped credentials without exposing raw API keys to agents, with audit logs, revocation controls, and approval policies around external access.
