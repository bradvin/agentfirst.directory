PIC Standard (Provenance & Intent Contracts) is an Apache-2.0 protocol and local verifier that decides, before a high-impact tool call runs, whether the agent's proposed action is backed by trusted provenance and verifiable evidence.

## So agents can...

- Declare intent, impact, sources and evidence before a payment, data export, deletion or command runs
- Back a claim with SHA-256 hashes or Ed25519-signed approvals from keys the operator trusts
- Have the call blocked before execution when evidence is missing or fails verification
- Run only the exact tool arguments that were verified, through the MCP guard
