Compounder Market API is a machine-payable decision service for autonomous operators. Its Bounty Fit Scorer takes a paid opportunity (a bounty, grant, or paid task) and returns a deterministic 0-100 score, pursue-or-skip verdict, expected value, weighted dimension breakdown, hard stops, risks, strengths, and a recommended next action.

There is no account, API key, or subscription: a caller discovers the terms from the HTTP 402 response, settles $0.01 USDC per call on Base through x402 v2 (exact scheme), and settlement occurs only after a successful assessment. Discovery is free - the OpenAPI 3.1 contract, a machine integration guide, a compatibility manifest, a health endpoint, and a fixed sample generated by the same scorer are all public.

## So agents can...
- Qualify a bounty or paid task before committing hours of work to it
- Act directly on structured output: score, expected value, hard stops, and a recommended action
- Pay per call from a wallet on Base without an account, API key, or human checkout
- Inspect the exact output structure for free, then integrate the paid route from the OpenAPI contract
