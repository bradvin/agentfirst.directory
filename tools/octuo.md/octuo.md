Octuo is a macOS assistant that coordinates the AI agents you already use. You state the goal; it prepares the work, hands each part to the right agent — Claude Code, Codex, or MCP tools — and follows up until the job is done. Long jobs continue after the chat closes, and the iPhone companion shows progress and decisions on the go.

## So agents can...

- Receive briefed tasks with the context each one needs, then return results into the same conversation.
- Keep working on long, multi-step jobs across sessions, with schedules and condition watches running on their own.
- Surface decisions that need a human to Attention, so work is reviewed before it is considered done.
