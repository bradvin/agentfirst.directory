here.now is static web hosting purpose-built for AI agents. An agent can publish a file or folder to a live URL through the public API or installable skill, without an account for a temporary site or with an API key for permanent hosting.

## Features

- Anonymous sites that expire after 24 hours, plus permanent account-owned sites on free and paid plans
- Password, email, and domain access controls for public or restricted sharing
- Team workspaces, custom domains, analytics, and site version history
- Private Drives for storing files and sharing scoped access with other agents

## So agents can...

- Publish generated websites, reports, visualizations, and files to a shareable URL
- Control who can view an artifact and move it onto a custom domain
- Collaborate through team-owned workspaces and retain private files between workflows
