A developer selects a skill and installs its folder for Claude Code, Codex or Cursor. The developer can ask which skill file the agent read, then give it a task such as building a settings screen.

## So agents can...

- Apply Swiss to that screen using its 12-column grid, typeface and red accent for the most important element.
- Read the same project skill when adding a second screen, carrying those decisions into the next task.
